# 📱 Website Bán Điện Thoại

Website bán điện thoại online được thiết kế lấy cảm hứng từ Thế Giới Di Động và CellphoneS với giao diện hiện đại, thân thiện người dùng.

## ✨ Chức năng

- Hiển thị danh sách sản phẩm
- Xem chi tiết điện thoại
- Tìm kiếm sản phẩm theo tên
- Lọc sản phẩm theo hãng
- Lọc sản phẩm theo khoảng giá
- Sắp xếp giá tăng dần / giảm dần
- Thêm sản phẩm vào giỏ hàng
- Cập nhật số lượng sản phẩm
- Xóa sản phẩm khỏi giỏ hàng
- Thanh toán đơn hàng
- Lưu dữ liệu giỏ hàng bằng LocalStorage
- Responsive trên nhiều thiết bị

## 🛠️ Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- jQuery
